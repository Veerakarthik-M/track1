📐 How Data Flows: JSON → SQLite → App

1
Collection — Data gathered from KochiTransport GTFS, kbuses.in (KSRTC schedules), Kerala Private Bus RTI, and manual curation
2
Normalization — Raw data cleaned into canonical JSON files (stops.json, routes.json, fare_stages.json, aliases.json, entities.json)
3
Database Build — build_database.py converts JSON into relational SQLite database (anavandi.db) with 7 normalized tables + indices
4
Browser Loading — sql.js (SQLite compiled to WebAssembly) loads the .db file in the browser. No server needed. Fully offline-capable
5
Application — The PWA currently reads JSON directly (faster for 31 stops); the SQLite path is ready for full Kerala (~3,000+ stops)
